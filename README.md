# Yufan Shi - Personal Portfolio

Personal website for Yufan Shi, an AI systems engineer and ECE graduate student at UC San Diego.

The site highlights work in reliable AI agents, retrieval-augmented generation, multimodal systems, and AIOps. It is built as a responsive Jekyll site for GitHub Pages.

## Featured work

- MedMARS - multi-agent medical question answering with hybrid RAG
- Multimodal E-commerce Agent - controllable shopping agent with image-text retrieval
- Multi-agent root cause analysis at Microsoft
- On-device large language model survey in *Artificial Intelligence Review*

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
